# ToDo App (Django)

Веб-приложение для управления задачами, разработанное на Django.

## Функционал
- Просмотр списка задач с сортировкой от новых к старым
- Отображение статусов выполнения с визуальной индикацией
- Просмотр детальной информации по каждой задаче
- Добавление новой задачи
- Переключение статуса задачи в один клик
- Панель администратора Django

## Установка и запуск

1. Клонировать репозиторий:
```bash
git clone https://github.com/wsfgcyhhj-art/cr1.git
cd cr1
```

2. Создать и активировать виртуальное окружение:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Установить зависимости:
```bash
pip install -r requirements.txt
```

4. Применить миграции:
```bash
python manage.py migrate
```

5. Создать суперпользователя (для доступа к админке):
```bash
python manage.py createsuperuser
```

6. Запустить сервер:
```bash
python manage.py runserver
```
