## 2. Ключевые инженерные правила для Django (Gstack + Karpathy)

1. **База данных и транзакции**:
   - Изменения связанных данных обязательно оборачивать в `transaction.atomic()`.
   - Любые выборки связанных сущностей в циклах оптимизировать через `select_related()` / `prefetch_related()`.
2. **Минимализм и чистота**:
   - Ранние возвраты (Guard Clauses) вместо вложенных `if/else`.
   - Тонкие Views / Fat Models или Service-слой для бизнес-логики.
3. **Безопасность и валидация**:
   - Валидация входных данных на входе (Django Forms / DRF Serializers).
   - Никаких секретов в коде — строго через переменные окружения.
4. **Проверка перед коммитом**:
   - Тесты проходят: `python manage.py test`
   - Миграции проверены: `python manage.py makemigrations --check --dry-run`
